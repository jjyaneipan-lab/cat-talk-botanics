# Cat Talk Botanics

A tiny pixel writing companion for growing a same-day garden while you type.

Choose a cat, write in the notebook, and the window garden keeps blooming with
pixel flowers. Garden notes are saved in the browser for the current day.

## Files

- `index.html` - main app
- `style.css` - pixel art layout and visuals
- `script.js` - cat reactions, flowers, notes, and daily storage
- `cat-prototypes.html` - archived design studies for the pixel cats

## Publish With GitHub Pages

This is a plain static site. In GitHub Pages, publish from the `main` branch and
the repository root.

The final URL will look like:

```text
https://YOUR-GITHUB-USERNAME.github.io/cat-talk-botanics/
```
